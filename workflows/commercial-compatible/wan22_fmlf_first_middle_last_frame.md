# Wan 2.2 First-Middle-Last-Frame to Video

Generates video from first/middle/last reference frames using Wan 2.2's multi-frame conditioning nodes.

- ComfyUI-VideoHelperSuite (GPL-3.0)

Install with `../../scripts/install-dependencies.sh` (see repo root) or manually via ComfyUI-Manager.
