The candidate is [wallen0322/ComfyUI-Wan22FMLF](https://github.com/wallen0322/ComfyUI-Wan22FMLF) at exact source commit `7140cd224396aff9fd909ab0041c3fbf81b92b0c`. The source uses the `comfy_api.latest` schema system; identifying the class in source does not establish compatible ComfyUI registration or inference.

## Fail-closed evidence

The [standalone source auditor](../scripts/audit_wan_fmlf_provider_candidate.py), exercised by [disposable CI](../.github/workflows/audit-wan-fmlf-provider.yml), checks out the **exact commit** into runner scratch. It parses three upstream Python files by AST, with **no import or execution of third-party code**. The auditor compares each declared `io.Schema` input name and type and each output name and type with every matching node instance in the two actual UI exports. The baseline is two first/middle/last instances, one four-frame instance, and one multi-frame instance, all exposing four outputs: `positive_high`, `positive_low`, `negative`, and `latent`. The source schema declaration must match exported UI socket names and types exactly; a changed class name, output, input or occurrence count fails the audit. It records only class names, public workflow filename/hashes and source hashes, never prompt contents, model filenames, private paths or media.

**License HOLD:** At this pinned revision, GitHub has no detected repository license, and the reviewed source tree has no LICENSE/LICENCE/COPYING/NOTICE/UNLICENSE file. The audit therefore reports `licence_file_detected=false` and **`commercial_redistribution_or_use_cleared=false`**, without guessing implied permissions. If a source licence file appears in a future revision, it must be reviewed before changing the baseline. This candidate must **not** be silently added to the `commercial-compatible` dependency manifest, staged as licensed, bundled, distributed, or installed in a production commercial deployment on the basis of this audit alone. Seek a verifiable explicit license or permission from the rights holder before any such promotion.

**Runtime HOLD:** No candidate modules are imported and no `/object_info` registrations are verified. The exports are **ComfyUI UI/editor JSON**, not directly executable API prompts. Even exact socket-name/type parity cannot establish extension/core-version compatibility, tensor shape validity, model weights, conditioning behaviour, model use rights, GPU/VRAM adequacy, or inference output. The original [native Wan audit](wan-native-source-bindings.md) remains valid: the same three classes are absent from the *pinned public ComfyUI core Wan source*. The separately identified external provider does not make those classes fork-native, core-native, or commercially cleared.
